# UI 规范

适用于 Lyrico Desktop 的页面、交互和界面文案。Agent 工作方式见根目录 [AGENTS.md](../AGENTS.md)。本文件只维护当前约定，具体实现和数值以列出的源码为准。

## 主题与尺寸

- 组件基座为 Ant Design，图标使用 `@ant-design/icons`。主题由 `src/app/App.tsx` 的 `ConfigProvider` 管理。
- 全局颜色、间距、字号、圆角和高度复用 `src/App.css` 的语义变量。共享数值在源码中统一修改，不在页面里复制另一套。
- 保持紧凑的工具界面，层级由对齐、留白、边框和次要色表达。不得新增渐变、玻璃模糊、装饰投影、大圆角卡片或悬浮位移。
- 内容容器使用共享圆角；封面、头像、裁剪遮罩和组件库内置形态按用途处理，不用“一律相同圆角”覆盖它们。
- 明暗主题均使用语义颜色，滚动条集中定义且可见。表格宽度不足时允许容器内横向滚动，页面不能出现无法操作的裁切。

## 页面与滚动

- 保留系统原生标题栏；布局和浮层问题在共享容器或窗口层解决，不靠各组件单独添加偏移量。
- 一级页面复用 `PageHeader`，内容放在 `.page-body`；二级页面用 `SubPageBar` 替换一级页头，不叠加标题和面包屑两行。
- 页头与二级条保持可见。页头左侧是标题与本页读数，右侧依次为搜索、排序或筛选、主操作。单项操作放在对应行或详情中。
- 页头行复用共享高度、字号和间距，常规窗口下保持单行，不用组件库默认标题字号覆盖共享尺寸。只显示本页数据，不添加功能简介；没有读数就不填 `meta`。空态已有主要入口时，页头不重复放同一动作。
- 页面滚动由 `.page-viewport` 管理；虚拟表格及插件、设置、批处理的固定工作区按已有结构由内部容器滚动。不要再叠加整页滚动或多个互相争抢高度的滚动层。
- 全局读数和持续任务摘要放在固定的 `.app-statusbar`；进度出现时不能在页顶插入横幅、推移内容。

## 共享组件

| 需求 | 使用 |
| --- | --- |
| 一级页头 | `PageHeader` |
| 二级返回、路径、本层操作 | `SubPageBar` |
| 边框面板 | `Panel`；避免卡片套卡片 |
| 空态 | `EmptyState`；一句事实，可附一个下一步动作，不使用默认插画 |
| 歌曲列表 | `LibraryTable` |
| 批处理表格 | `BatchTable` / `BatchTrackTable` |
| 排序选择 | `SortSelect` |
| 拖动排序 | `SortableList`；复用 dnd-kit、DragOverlay 和键盘排序 |
| 任务进度 | `ProgressBar`；未知进度用不确定状态，不只显示裸百分比 |

动作使用 `Button` 或原生 `button`；布尔设置使用 `Switch`，多项选择使用 `Checkbox`，互斥选项按上下文使用 `Select`、`Radio.Group`、`Segmented` 或 `Tabs`。不自造可点击的 `div`、嵌套按钮或重复一套排序组件。图标按钮必须有可访问名称，鼠标悬停才出现的动作也要支持键盘聚焦。

## 歌曲选择与导航

歌曲页、文件夹内歌曲、专辑详情和艺术家详情共用以下行为，不各自增加多选模式：

| 操作 | 结果 |
| --- | --- |
| 点击行内容，包括按住 Shift/Ctrl 点击 | 打开编辑抽屉，不改变选择 |
| 点击首列勾选框 | 切换当前歌曲的选中状态，不打开编辑 |
| Shift + 勾选框 | 从选择锚点到当前项选择区间，可向两侧扩展或缩小 |
| Ctrl + Shift + 勾选框 | 将区间加入已有选择 |
| 方向键 / Home / End | 移动光标并改选当前项 |
| Shift + 方向键 / Home / End | 从锚点选择区间 |
| Ctrl + 方向键 | 只移动光标 |
| 空格 | 切换光标所在歌曲；Shift + 空格按锚点选择区间 |
| Ctrl + A | 将共享选择替换为当前列表的全部歌曲 |
| Enter | 打开光标所在歌曲 |

- 勾选框阻止行点击冒泡，鼠标与键盘共用选择规则。排序或筛选后，锚点与光标跟随歌曲路径；虚拟行卸载后键盘焦点不能丢失。
- 表头勾选框显示全选或半选，操作同一份全局“已选歌曲”：全选替换为当前列表，取消全选清空共享选择。不得擅自保留另一页面的独立集合。
- 专辑和艺术家网格保留显式选择模式；模式内磁贴选择整个集合，模式外打开详情。不要把此规则移植到歌曲行。
- “已选歌曲”是独立一级页面，可搜索、移除单项、清空；批处理从主导航进入。选择变化不插入额外工具栏，不改变页头高度。
- 二级页面的鼠标后退侧键与返回按钮作用相同，只上移一级；前进侧键不触发返回。弹窗或抽屉打开时不操作底层页面。

## 弹窗、反馈与保存

- 删除、卸载等破坏性动作使用居中 `Modal`，明确对象、取消和确认动作，不使用气泡确认框。标题和按钮已表达的内容不在正文重复。
- 首次关闭窗口用 `CloseBehaviorDialog` 选择“最小化到托盘 / 退出应用”；确认成功保存后不再询问，重启后仍有效。取消不记录选择，保存失败保留弹窗，保存中不能重复提交。
- 关闭方式在设置中以“关闭窗口时”的 `Select` 显示，沿用弹窗的动作文本，只保留“可在设置中更改”这类必要提示。
- 短操作反馈用 `Message`，扫描和批处理完成用 `Notification`；失败提示保留具体原因或处理入口，持续进度使用固定区域。
- 编辑抽屉中的在线匹配结果只应用到草稿，保存后才写入文件。切换模式、来源、分页或编辑页签时保留当前会话；关闭或换歌后清理。
- 抽屉关闭时保留挂载到 `afterOpenChange(false)`，不截断动画；切换页面、歌曲或任务后忽略旧请求结果。
- 列表页排序和批处理当前功能持久化；二级歌曲表的临时排序和各批处理功能内部选项不额外持久化。

## 页面约定

- **插件**：仅向用户展示标签、歌词、封面三种分类；各分类的启用状态和顺序独立。左栏为插件列表，右栏为详情与配置，不重复启停、卸载操作。保存固定在详情头，配置有修改才可保存。拖动顺序与实际调用顺序一致，写入失败恢复原状态，避免并行写入覆盖新选择。
- **批处理**：处理歌曲和任务历史使用已有分区，操作通过分组 `Select` 选择。配置、主操作与总进度保持可见，表格主体独立滚动；逐首详情按需打开，不把大量低频字段铺满列表。字段复用设置中的顺序和显隐，`<keep>` 表示不修改，空值表示清空。
- **设置**：左侧分类、右侧平铺表单，不使用装饰卡片；标题直接说明设置对象，说明按需出现。字段排序复用 `SortableList`；ReplayGain 成员作为一组移动，组内排序和显隐在弹窗管理。
- **文件夹、专辑和艺术家详情**：复用 `SubPageBar`，展示真实路径或集合名称；摘要下接同一个歌曲表格。本层操作留在本层，全局操作放回一级页面。

## 界面文案

- 使用常见动作词和事实描述。标题、按钮、状态各承担一种信息；不使用英文眉标、宣传语、鼓励语、装饰性 emoji 或 `·` 串联字段。
- 中文短句不加末尾句号。数量带对象，时长、大小等数值带格式或单位；中英文资源的含义与入口保持一致。
- 说明只保留名称不能表达的条件、影响或恢复方法，不常显长篇功能解释。必要的警告不因精简而删除。
- 示例：“选择关闭方式，并在后台继续运行……”缩为标题“关闭窗口时”与两个动作选项；无需给每个选项再写一段解释。
- 不混淆清空与不修改、转换与整理、隐藏与退出，不把内部协议字段或实现细节直接作为用户分类。

## UI 走查

按本次改动检查相关页面与主流程：组件复用、动作范围、焦点、滚动、浮层、取消和失败路径。布局改动查看最小窗口和常规窗口下的明暗主题；窗口尺寸以 `src-tauri/tauri.conf.json` 为准。共享组件修改覆盖所有调用页面，局部修改不强制检查无关页面。

通过标准：主操作与前置条件可见可操作；没有裁切、重叠或额外整页溢出；相同组件的间距与样式一致；没有翻译键泄漏或新运行时错误；实际交互符合本文件。是否需要测试脚本、构建以及如何报告验证范围，遵循 `AGENTS.md`。
